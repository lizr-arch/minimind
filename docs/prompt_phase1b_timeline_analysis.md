## 请完成以下分析

### 1. 变化频率基础分布

已有初步统计（均值 31.8，中位数 20，P10=3，P90=76，P99=158）。补充：

- 按联赛统计平均事件数和中位数

- 按 bookmaker 统计事件数分布（Pinnacle vs Bet365 vs Sbobet vs Macau）
- 总结：哪些比赛的 odds_timeline 最"活跃"、哪些最"安静"？

### 2. 变化方向统计

对每个市场（欧赔、亚盘、大小球），计算：

- 开盘→收盘的变化方向分布：
  - 欧赔：主胜赔率上升/下降/不变的比例
  - 亚盘：盘口升/降/不变的比例，水位升/降/不变的比例
  - 大小球：盘口升/降/不变的比例
- 开盘赔率隐含概率 vs 收盘赔率隐含概率的变化幅度分布（KL 散度或绝对值差）
- 哪些联赛的变化最大？哪些盘口类型（如 -0.25 quarter-ball）变化最频繁？
- 变化方向是否和比赛结果一致？（如收盘时主胜赔率下降 → 主队确实更可能赢？）

### 3. 变化速度与加速度

- 最后 1 小时内的变化次数 / 总变化次数（临场变化占比）
- 分段统计变化密度（事件数/小时）：
  - 开赔→赛前 72h
  - 72h→24h
  - 24h→6h
  - 6h→1h
  - 1h→0h（最后 1 小时）
- 是否存在"安静→临场爆发"的模式？占比多少？
- 临场爆发模式 vs 比赛结果的关系（首发公布后的大变化是否更准确？）

### 4. 事件数 vs 预测准确度（核心假设验证）

**用户假设：赔率变化少的比赛 = 庄家初始判断未被市场修正 = 初始赔率可能更准（或无人关注）。**

验证方法：
- 将比赛按事件数分为 4 组：极低（1-5）、低（6-15）、中（16-50）、高（50+）
- 每组计算收盘欧赔去水后的 accuracy、logloss、ECE
- 再拆开：每组也计算**开盘**欧赔去水后的 accuracy、logloss、ECE

关键解读：
- 如果极低事件组开盘 accuracy > 收盘 accuracy → 开盘判断已被市场噪声污染，低事件比赛更难预测
- 如果极低事件组收盘 accuracy > 其他组 → 庄家初始定价确实更准，市场修正无增量
- 如果事件数和 accuracy 无系统关系 → 事件数不携带预测信号

**额外分层：** 热门联赛（EPL, LaLiga, Bundesliga, SerieA, Ligue1）vs 冷门联赛分别分析。如果只有冷门联赛低事件 = 低准确度，那是"无人关注"效应。

### 5. H4 Lead-Lag 分析

需要同时有 ≥2 个庄家数据的比赛。v6_phase1a.jsonl 中同一 match_id 有多行。

方法：
- 找到所有有 ≥2 个庄家（最好同时有 Pinnacle + Bet365）的比赛
- 对每个市场（欧赔、亚盘），在每个时间窗口内比较各庄家的赔率变化：
  - 提取每个庄家赔率发生"实质性变化"的时间戳（变化幅度超过阈值 ε，如欧赔变化 >0.05）
  - 配对比较：Pinnacle 先变 vs Bet365 先变的比例
- 统计指标：
  - Pinnacle 领先 Bet365 的平均时间差（分钟）
  - 领先庄家的变化方向和滞后庄家的最终变化方向是否一致？
  - 如果 Pinnacle 变了但 Bet365 还没变，Pinnacle 的变化方向能否预测 Bet365 后续的变化方向？（可交易的信号）
- 按联赛分层：不同联赛的 lead-lag 模式是否不同？
- 结论：是否存在一个 exploitable 的 lead-lag 信号？如果存在，能否在 Phase 1b 中作为特征？

### 6. 欧赔和亚盘的动态背离

H6 已验证静态欧亚不一致是"主队被高估"信号。动态版本：

- 同一比赛的时间线中，欧赔降（主胜赔率下降）但亚盘向客队方向倾斜（如 line 从 -0.5 → 0.0 或上盘水位上升）的事件占比
- 背离事件的发生时间和比赛结果的关系：背离越早出现 → 信号越强？还是越接近比赛 → 越强？
- 背离方向（欧赔偏向主队 vs 亚盘偏向客队）和实际结果的一致性
